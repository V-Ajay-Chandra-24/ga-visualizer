    Summary

    Settings

    as in notes

    Roulette wheel: each spin selects the first string with qi ≥ r. Single-point crossover on pairs (1, 2), (3, 4): cross if rc < pc. Bit-flip mutation: flip if rm < pm.

    Encoding

    Random numbers (exam sheet)

    Type the numbers you are given, exactly as in an exam. Any blank cell is filled from the seeded RNG (rounded to 3 decimals) and marked rng in the tables. Mutation: list the flipped bits as child:bit=r_m (bit counted from the left), write none for no flips, or leave the cell blank to draw rm for every bit.

    Zero-dependency, single-file. The random numbers come from a seeded mulberry32 generator, so a given seed always gives the same run.
